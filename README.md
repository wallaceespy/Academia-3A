# 🏋️‍♂️ Academia 3A - Sistema Integrado Web

*Sistema web completo para gestão de academias com agendamento, natação e nutrição.*

## 📌 Visão Geral
Solução web desenvolvida para a **Academia 3A** contendo:
- **Site institucional** com informações da academia
- **Sistema de agendamento** integrado ao WhatsApp
- **Portal de natação** com horários e cursos
- **Blog nutricional** (NutriFit) com artigos especializados

## ✨ Funcionalidades Principais
| Módulo | Recursos |
|--------|----------|
| **Agendamento** | Reserva de aulas via WhatsApp, confirmação automática |
| **Natação** | Grade de horários, perfil de professores, tipos de curso |
| **Nutrição** | Artigos sobre suplementação, dietas e alimentos |
| **Administrativo** | Exibição de planos, localização e contatos |
